Voices and models

On Qwen3-TTS, CustomVoice carries the preset speakers, Base does voice cloning and VoiceDesign builds a voice from a description. MOSS-TTS has no presets: the 1.7B does speech and cloning, VoiceGenerator does descriptions. Each engine needs its own tokenizer.

Set up the engines

Qwen3-TTS and MOSS-TTS each get their own ComfyUI, their own Python environment and their own models folder, so neither engine's packages can break the other's. Only the one you are using runs — two engines on one card would each hold their models in video memory, and neither can free the other's. Switch between them on the Create page.

No Git or Python yet? The Engine page installs them for you.
