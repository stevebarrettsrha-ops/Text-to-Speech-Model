Set up the engine

Script Builder speaks with Qwen3-TTS running on this machine through ComfyUI. The first run installs ComfyUI, adds the Qwen-TTS nodes and downloads the voice models. After that it starts on its own.

No Git or Python yet? The Engine panel installs them for you.
